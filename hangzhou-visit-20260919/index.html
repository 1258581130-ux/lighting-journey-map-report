01 / THE CENTRAL FINDING

满意，不等于没有遗憾

一个总体满意、仍有真实不适的案例。
两种声音都应当留下来

核心判断 · 基于本案例的分析

简顿已提供有价值的配灯与调整服务。
下一步，是帮没有专业能力的用户，
也把想要的生活感受，真正落到家里

已经被这个案例支持产品适配、点位选型建议、退换与智能升级配合，得到了用户认可。
还不能由这个案例证明完整空间构想由屋主主导，智能由夫妻搭建；不能据此证明简顿的从零全案设计能力。
查看依据 · 24:22 / 36:24 / 01:04:42
“我是给到了他我的灯具的点位，他在我的灯具点位上把你们的灯放进去了。”
“我跟他说了我是设计师。我没有这种需求。跟他说，你帮我配一下灯。”
《回访 2》24:22—24:53、36:24—37:57、01:04:42—01:05:55。智能搭建由夫妻完成，不归入简顿交付。

THE PERSON / 用户与需求

他想买的，是回家之后的放松

有室内设计经验夫妻共同决策已有明确灯位与吊顶构想

原来的精装房太像工作中的项目。屋主希望玄关先让情绪沉下来，独处时只留下几处氛围光，需要会客时再亮起来

原话与时码 · 25:14—27:06
“走进来这个过程，是你从外面到家，从工作到回家这个状态转变的一个过程。”
《回访 2》25:14—27:06；职业与夫妻共同决策见10:26、16:44—16:55。

THE CHOICE / 选择逻辑

不只是好看，还要配得上、少折腾

窄边框 / 浅埋深颜色协调智能与成套适配

从小红书找到产品，再去淘宝了解。外观、安装条件、配色、缓亮缓灭和预算共同影响选择；“愿意为美买单”不等于不看价格

原话与时码 · 17:03 / 20:38 / 51:10
“我就找那种深度不是很深的……窄一点的边框。”
“我灯我一开始就留了1万块钱，但实际上后期是超了的。”
《回访 2》17:03—17:58、20:38—22:53、51:10—52:49。预算为用户自述，不是核实后的订单金额。

案例定位：设计师自宅的配灯深化。不是普通用户从零购买全案设计的代表样本

02 / THE CUSTOMER JOURNEY

从选灯，到真实入住

按实际经历拆成八个触点。
点击阶段，查看事实与改进机会

01 / 事实

先有想要的生活，再有灯位

不喜欢精装房唤起工作状态。希望进门时放松，独处时安静，同时保留会客时足够亮的选择

依据：《回访 2》25:14—27:06

分析 · 服务机会

需求确认不要停在“风格、面积、亮度”。先问最不想出现什么感觉，以及回家后真正会做的事

02 / 事实

入口是具体的产品适配

为窄边框、浅埋深等条件刷小红书，看到简顿后去淘宝看产品。已有需求在先，不是被设计服务宣传从零教育

依据：《回访 2》17:03—17:58

分析 · 服务机会

内容既要给人看到整体效果，也要回答“这类灯能不能装进我家”。不要将本单写成设计服务内容直接获客

03 / 事实与缺口

有付费，尚缺完整决策记录

屋主自述“去年10月28日”加客服，也明确买过设计服务。具体设计费、付款节点与当时顾虑，访谈没有交代清楚

依据：《回访 2》23:51、01:04:54

待核实 · 不提前下结论

用聊天与订单补齐决策过程、服务承诺及付费时间。不能据此计算设计服务带来的增量成交

04 / 事实

屋主定方向，简顿参与深化

屋主给灯位图和吊顶图，设计顾问配产品、建议筒射灯选择；屋主又减少部分点位。空间意图由屋主主导

依据：《回访 2》24:22—24:53、53:19、01:04:42

分析 · 服务机会

对专业客户尊重其已知需求；对普通客户，需要解释灯位背后的使用场景与原因。二者不能用同一交付假设

05 / 事实

改了很多次，沟通仍然顺畅

多次退换、补充智能功能，用户评价流程顺畅。丈夫沟通、妻子账号下单，客服有时会混淆两人的身份

依据：《回访 2》47:01—47:59

分析 · 服务机会

以家庭项目关联沟通人与订单，讲清可调整范围。让用户知道哪些是正常服务，不必觉得自己一直在“麻烦你们”

06 / 事实

好方案，也会卡在施工现场

油工拆灯时磕掉金属灯杯漆；部分灯具忘记提前准备，后补射灯；梁与安装深度也限制了原想法

依据：《回访 2》44:52—45:42、01:13:23—01:15:24

分析 · 服务机会

施工前复核预埋、深度和灯具准备情况；拆灯保护说明不仅给安装师傅，也要覆盖后续返工与其他工种

07 / 事实

氛围被喜欢，不适也真实存在

夫妻自行搭建智能，认可调光与场景控制。同时反馈部分射灯刺眼、金属灯杯烫手，妻子的不适由屋主转述

依据：《回访 2》36:24—38:45、38:56—42:15

分析 · 服务机会

按真实坐姿、动线与使用模式核查不适。发热体感不能直接判定合格或不合格，需由产品与售后进一步检查

08 / 事实与缺口

被重视之后，会产生新的期待

用户感受到专程回访的用心。现场讨论了新杯色、试灯和安装支持，但数量与安排仍有变化

依据：《回访 2》43:24—44:41、01:07:56—01:08:22

待完成确认 · 不等于已交付

逐一确认型号、杯色、数量、安装和回收反馈方式。记录未证明寄送、安装或体验改善已完成

01 / 08

说明：这是单户经历的结构化整理，不是各阶段的量化评分，也不是已验证的设计服务转化漏斗

03 / EMOTIONAL TOUCHPOINTS

好评之外，听见不舒服

正向节点与负向节点同时存在。
未对情绪强度打分，也不强排高低

↑ 正向体验 / 01

灯光让情绪慢慢放下来

“能够给我带来松弛的、安静下来的角落，我都非常享受。”

沙发只留两侧氛围灯，浴缸保留重点照明。喜欢的不是全部打开，而是符合当时的状态

分析：真正被感知的价值，是生活里的具体时刻

依据 · 01:58:57
《回访 2》01:58:57—01:59:23，正式采访中谈最喜欢的角落。此处保留原意，去除口语重复。
↑ 正向体验 / 02

反复调整，仍然有人配合

“挺顺的……我很多事情感觉都是在麻烦你们。”

退换与智能升级获得配合。但用户把部分调整理解成“麻烦别人”，服务边界是否被讲清仍值得确认

建议：主动说明可以找谁、改什么、何时联系

依据 · 47:14—47:45
《回访 2》47:14—47:45；01:59:30再次肯定升级改造配合。“边界不清”是待验证假设，不是既定事实。
↑ 正向体验 / 03

不是大单，也被认真对待

“就会让我觉得你们很用心。”

专程来了解体验，超出了他的预期；与家中石材相呼应的洞石台灯，也得到多次正面反馈

分析：有针对性的在意，比泛泛地说重视用户更具体

依据 · 06:16 / 01:08:22
《回访 2》06:16—06:23、01:07:56—01:08:22。礼物匹配让用户感到被理解，是分析解释，不是用户逐字结论。
↓ 负向体验 / 01

刺眼被接受，却没有被解决

“我老婆一直在说很刺眼很刺眼。”

屋主用“买到这样已经不错了”安慰自己和爱人。现场进一步指向部分射灯，也提到金属灯杯烫手

优先动作：核查具体灯具与使用场景，不用解释代替检查

依据 · 38:56—42:15
《回访 2》38:56—39:24、40:15、41:14—42:15。妻子感受为屋主转述；发热为体感反馈，不代表已测温或判定不合格。
↓ 负向体验 / 02

灯杯磕掉漆，用户很心疼

“把我那个灯杯上的漆……磕掉了，我当时就好心疼。”

油工为返工拆灯，弹簧卡子弹下，磕伤金属灯杯。用户指出电工和安装师傅通常知道要小心

准确归因：受损的是灯杯漆，不是艺术漆墙面

依据 · 44:52—45:42
《回访 2》44:52—45:42。问题出现在其他工种拆灯时，不能笼统归为灯具质量或安装师傅失误。
↓ 负向体验 / 03

想法还在，精力已经不够了

“现在根本没有心思去搞了。”

装修拖延、催工和赶入住消耗了热情。想做内容、添灯和完善角落，却说自己“有心无力”

分析：此时更有价值的，可能是少折腾，而非更多推荐

依据 · 14:20 / 01:38:55
《回访 2》14:20—15:13、01:38:16—01:38:55。装修疲惫来自整体经历，不能全部归因于简顿。

04 / WHAT WE DID NOT EXPECT

四个容易被好评盖住的发现

从具体事件中提出假设，
再决定哪些值得继续验证

01

服务对象是一个家庭，
不是一个微信联系人

丈夫沟通，妻子下单、查负面评价并参与智能搭建。两个人对不适的接受程度不同，单人的满意不能代表全家

建议：关联沟通人、付款人与主要使用者；补听妻子的直接感受
依据 · 47:45 / 49:41 / 41:14
《回访 2》47:45—47:59、49:41—50:06、41:14—42:15。
02

“不知道你们有”，
不等于“你们没有”

浴缸上方灯具在其他店购买，回访才知道简顿有相关产品；小开孔灯还涉及当时产品条件与未推荐的信息差

建议：先分清缺产品、不适配、没讲到，再决定是否开发新品
依据 · 07:10 / 54:41 / 01:10:33
《回访 2》07:10—07:23、54:41—54:54、01:10:33—01:12:09。小开孔产品是否适合当时需求，仍需复核。
03

设计价值不只是一张图，
还在于替用户想到

屋主建议向普通用户提供氛围、重点照明和智能场景建议，解释为什么这样布灯，而不是只发点位图

待验证：这些交付是否让普通用户更理解设计价值、更愿意付费
依据 · 01:04:05—01:05:55
《回访 2》01:04:05—01:05:55。这是受访者对普通用户的建议，并非其他用户已经验证的结论。56:45曾提到请求照度图未获提供，具体交付约定待核实。
04

被什么吸引、常待在哪里，
与最喜欢什么，并不一样

他认为大场景更能打动自己；实际待得多的是卧室；最喜欢的角落则是沙发与浴缸

建议：用整体氛围吸引，用真实作息理解需求，用珍惜的时刻做个性化设计
依据 · 48:24 / 01:02:45 / 01:58:57
《回访 2》48:24—49:01、01:02:45—01:03:31、01:58:57。内容建议属于本报告的分析推论。

05 / FROM INSIGHT TO ACTION

先做好三件事

以下均为建议动作，不代表已分派或完成。
先处理这户，再把有效做法纳入服务

01

优先 / 用户问题收尾

先处理不舒服，
再扩大案例合作

核查射灯不适、发热反馈与灯杯受损情况。确认试灯型号、杯色、数量及安装安排，避免增加新的折腾

交付物

一份双方确认的处理记录，包含现状、处理方式与回收反馈

完成标准

不是“寄出就结束”，而是用户确认处理结果，或明确下一步

建议协作：内容负责人 × 产品 × 售后

02

试点 / 服务动作补齐

设计前问生活，
施工前查条件

需求确认加入生活动作与家庭成员差异；施工前复核梁位、安装深度、预埋与留线；入住后按场景检查

交付物

一页简版服务确认清单，不增加复杂附表

完成标准

每个检查点有确认人、处理结果；智能搭建与调试责任说清楚

建议协作：设计顾问 × 安装 / 施工对接

03

补证 / 完整案例归档

把聊天、订单与
实际结果对起来

补齐付费与交付约定、选型修改、退换和实际购买清单，再归档后续试灯效果。保留未解决项

交付物

一份可追溯的案例记录与可对外使用的准确口径

完成标准

分得清谁设计、谁交付、哪些已完成，哪些仍待验证

建议协作：内容负责人 × 设计顾问 × 订单对接

现场承诺，要单独确认 试灯、杯色与安装支持在对话中仍有调整；本报告不将它们写成已兑现的服务。

06 / TURN THE CASE INTO CONTENT

用生活吸引，用事实建立信任

建议内容主线 / 非逐字原话

“我不想回到家，
还像在上班。”

一个有设计经验的屋主，怎样用灯光让自己真正放松。重点不是堆满参数，而是讲清楚每一处光为什么存在

选题依据 · 26:32—27:06
屋主说原精装与自己工作中的项目太相似，明确表示“不想把工作带回家，一定要松弛”。标题为编辑提炼。
1

先看到差别

整体空间与模式切换，展示不同使用状态，而非只拍全亮画面

2

再进入生活

玄关如何过渡情绪，沙发如何安静独处，浴缸如何放松

3

最后说清帮助

简顿参与的配灯深化、选型建议、调整与升级配合。归属不扩大

不是全案作品

空间构想由屋主主导。建议称“简顿参与配灯深化的设计师自宅案例”

不是全部简顿灯具

餐吊灯、浴缸上方等灯具来自其他渠道，最终清单需核对

不是全部统一色温

现场模式与色温曾记混。发布前核对实际设置，不统一标成3500K

不是通用设计模板

亮度偏好、生活方式与装修条件属于这户，不外推为普遍需要

依据：《回访 2》07:10—07:23、24:22—24:53、36:24—37:30、01:20:56—01:24:09。正式内容发布前，另行确认素材授权与品牌、设计归属

07 / REFLECTING ON THE INTERVIEW

先听完，再解释

让关系松下来，也让问题留得住

01 / 少一点立即解释

不要把反馈聊成产品答辩

用户刚说烫手，现场就接到“散热好”。更有效的是先记录型号、触摸位置、运行状态与后续核查

依据：《回访 2》38:56—39:13

02 / 接准具体受损对象

灯杯漆，不是墙面漆

用户讲的是金属灯杯被卡子磕伤，回应却转向艺术漆墙面。复述一次问题，可以避免处理方向错位

依据：《回访 2》44:52—45:58

03 / 分开自然聊天与出镜评价

不能只留下最后的好评

正式拍摄前，用户提到“配合你们营业”。这不否定好评，但应与自然聊天、具体负面事件分别保存

依据：《回访 2》01:51:39、01:59:30

“当时具体发生了什么？后来怎么处理？
现在算解决了，还是只是先接受了？”

THE NEXT CHAPTER

真正的回访，
是让不舒服少一点

把用户喜欢的生活时刻，变成能被理解的设计价值；
把用户忍下来的遗憾，变成有人负责的服务动作

展开 · 可直接用于汇报的摘要

这次回访看到，用户认可我们的产品适配、配灯专业度和后期调整配合，但这个家主要由屋主自己设计，智能也由夫妻搭建，所以还不能把它当作我们完整个性化设计能力的证明。真正值得放大的，是灯光帮助用户从工作状态切换到放松状态；需要先处理的，是部分射灯刺眼、发热反馈、灯杯安装保护，以及选型信息没有充分传递的问题。下一步先把这户的反馈处理闭环，再把生活需求确认、施工前复核和入住后的场景检查补进服务。我们要做的不只是把这套房拍好看，而是弄清楚：普通用户没有屋主这样的专业能力时，我们能替他多完成哪些事情。
